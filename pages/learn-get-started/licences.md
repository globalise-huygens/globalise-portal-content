## Datasets published so far

Datasets that Globalise published on DataverseNL during the project each have their own licence, which is stated in the dataset record:

| Type of dataset | Licence |
| --- | --- |
| VOC transcriptions (2023, 2024) | CC0 1.0 |
| Ground truth for text and layout recognition | CC BY-SA 4.0 |
| Text recognition and layout models (Loghi, Laypa) | CC BY 4.0 |
| Reference datasets and thesauri | CC BY 4.0 or CC BY-SA 4.0, depending on the dataset |

Always check the licence in the record of the dataset you use.
