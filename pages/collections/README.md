# Collections

Collections provide structured entry points into selected categories of Globalise data and archival material.

## Planned collection categories

- Events
- Objects / commodities
- Persons
- Places
- Ships & voyages
- Other categories to be determined

## Contributor template

Individual Collections should normally explain:

1. What the collection contains.
2. Why it is useful for research.
3. What users can find in Globalise.
4. How to reproduce or adapt example searches.
5. A selection of representative scans/documents.
6. Important limitations or contextual issues.
7. Further resources.

Substantive Collection pages will be commissioned from external contributors.
