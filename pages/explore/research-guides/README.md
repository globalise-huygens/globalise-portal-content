# Research guides

Research guides show how Globalise can be used in practice. Some start from a category of material, such as persons, places, ships or commodities, and explain what can be found and how to search it. Others start from a historical field or question, such as environmental history or the history of slavery, and show which data, searches and documents can help.

## Contributor templates

There are two templates, one for each kind of guide. Substantive guides will be commissioned from external contributors.

### Guides to a category of material

Use [`templates/collection.md`](/templates/collection.md). These guides should normally explain:

1. What the collection contains.
2. Why it is useful for research.
3. What users can find in Globalise.
4. How to reproduce or adapt example searches.
5. A selection of representative scans/documents.
6. Important limitations or contextual issues.
7. Further resources.

### Guides to a historical theme

Use [`templates/theme.md`](/templates/theme.md). These guides should normally explain:

1. Why this theme is worth researching.
2. Which research questions Globalise can help investigate.
3. Which data, entities and search functions are useful.
4. How to formulate searches.
5. Example documents and archival material.
6. Limitations and biases.
7. Further reading and resources.
