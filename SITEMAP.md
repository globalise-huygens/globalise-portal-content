# Sitemap

The navigation structure of the Globalise research portal. Each page links to its source file; IDs refer to the production plan in [CONTENT.md](CONTENT.md).

The navigation bar has four sections: Explore, Learn & get started, About GLOBALISE and Research responsibly. Home is reached via the logo; the remaining pages are linked from the footer.

## URLs

Folder names determine where a source file lives, not necessarily its final URL. Navigation labels may change, so keep URLs short and topic-based (for example `/ethics/policy` or `/data/overview`) so that renaming a navigation item does not break links.
